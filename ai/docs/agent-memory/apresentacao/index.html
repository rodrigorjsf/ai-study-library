O ciclo escrever → gerenciar → ler

Um LLM não lembra nada entre chamadas. Toda memória de agente é um laço que captura, organiza e devolve contexto à próxima sessão (Du, 2026, arXiv:2603.07670).

O que a literatura cobra de uma memória

  • Seletividade: mais contexto piora o modelo (Context Rot, Chroma 2025; Lost in the Middle, 2023)
  • Busca híbrida: BM25 + embeddings reduziu falhas de recuperação em 49% (Anthropic, 2024)
  • Esquecimento: decaimento inspirado em Ebbinghaus (MemoryBank, 2023)
  • Desconfiança: com menos de 0,1% de envenenamento, o AgentPoison passa de 80% de sucesso
  • Servidor local seguro: MCP exige validar Origin contra DNS rebinding

09 · PARTE A · CADA ITEM FECHA UM ACHADO DO CAPÍTULO 03 OU 07

O fork: seguro por padrão e de primeira classe no Cursor

A0 · GOVERNANÇA Fork controlado
  • Tag 3.0.x fixada, sync mensal + imediato em GHSA
  • Build reprodutível, cosign, SBOM, provenance
  • rustls ≥ 0.23.46; espelho interno, sem curl | sh
A1 · SEGURO POR PADRÃO Fecha H1, M1–M5, L1–L4
  • Auth obrigatória mesmo em loopback
  • bootstrap sanitizado; require_approval = true
  • Captura por allowlist; digest de perfil desligado
  • Tokens de agente sem ferramentas destrutivas
  • Webhook de segredos bloqueante; retenção 90 dias
  • Kill switch de egresso; audit log encadeado
A2 · TLS E CA CORPORATIVA Funciona atrás de inspeção TLS
  • Já lê o trust store do SO (native roots)
  • Novo: [tls] ca_bundle e certificado de cliente (mTLS)
  • Hooks nativos herdam a config; proxy com PKI interna
  • codegraph: NODE_EXTRA_CA_CERTS · Neptune: AWS_CA_BUNDLE
A3 · POLÍTICA DE LLM Interno ou vendor ZDR
  • Padrão: nenhum llm_provider
  • Host do LLM precisa estar na allowlist
  • Reranker LLM proibido no perfil vendor
A4 · TOPOLOGIA HÍBRIDA Local por padrão, time opcional
  • Perfis enterprise-local e enterprise-team
  • Um servidor por fronteira de confiança, OIDC
  • MDM: binário assinado, CA, hooks em /etc/cursor
A5 · CURSOR DE PRIMEIRA CLASSE Contexto chega de verdade
  • sessionStart devolve additional_context
  • Handoff em duas fases (reserva + confirma, mesmo session_id)
  • preToolUse responde permission: allow
  • afterAgentResponse, subagentes, escopo de projeto
Princípio Preferir pontos de extensão (config, admission webhooks) a mudanças no núcleo, e propor upstream as correções do Cursor (A5.1, A5.2), para o fork não divergir.

  • Credenciais temporárias via IAM Identity Center; nada em mcp.json
  • Audit logs (Database) e CloudTrail data events (Analytics)
  • Resultado do Neptune tratado como conteúdo não confiável

  • Time: estação resolve âncoras e envia metadado; servidor checa só a master
  • Credencial própria, só para metadado de âncora
