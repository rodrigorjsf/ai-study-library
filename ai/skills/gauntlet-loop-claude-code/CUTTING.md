# Cutting the work

Open this in every loop when you scout and cut the pieces (*Starting a loop* step 3), before you fan
out builders, and when verdicts come back to be attributed.

## Cut where a critic can judge one piece alone

Split the work into **the smallest pieces that can be improved and judged independently**; the
second half is the whole test. A piece a critic cannot evaluate without opening three others is not
a piece.

**Coupled work goes to one owner, in sequence.** Fan out over tightly coupled parts and each
builder optimises its own against a bar the others are also moving; they converge on nothing. More
agents available is no reason to split.

## Before the builders fan out

- **Settle the shared terms first.** Four parallel builders once gave four shared terms four
  spellings, and round 2 needed six terminology decisions to converge. The brief's glossary names
  each shared term once; builders confirm against it.
- **A piece that describes the others is built after them.** A docs chapter drafted from the
  brief, in parallel with the skills it documented, drew hand-off edges the skills' own text did
  not support: a wasted round by construction.

## Between the pieces

A defect between pieces (two claiming the same ground, a term one defines and another redefines,
an interface each implements differently) is invisible from inside either: each critic passes its
own piece honestly and the collision survives every round. Three such defects once survived four
clean rounds. That is why the round's **sweep** holds every piece at once, every round.

Past the pieces, the work can make something untrue in a file nobody graded; the main page's
iron-law check (*When the loop ends*, row 5) reads the whole repository for it.

## Attributing what comes back

Attribute each returned verdict by what its worker was **asked**, never by what its output
mentions. Workers read shared briefs that name every piece, and the sweep opens the other pieces on
purpose, so matching on content assigns a verdict to whichever piece is named most. It fails
quietly: the next round fixes a defect that was never there. Key every verdict file by the key the
worker was given.
